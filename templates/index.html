ℹ How It Works
▼
Human-in-the-loop: Every database query exposes a live SPARQL Console. Edit the generated query and hit Run ↵ to re-execute it instantly.
Visualizations: Ask for charts by type — bar, pie, or horizontal bar — and the agent will automatically render one from the query results.
Schema: Works are typed dbo:Work + schema:CreativeWork with dcterms: properties (title, creator, subject, date, type, format, identifier, language, isPartOf). Authors are linked via dcterms:creator and carry foaf:name, dcterms:alternative (Hungarian name order), and owl:sameAs links to external authorities (NSZL, VIAF).
